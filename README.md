# Breakdowner

## Overview
Distortion Plugin made by Metalheads, for Metalheads. Want your riffs, breakdowns, and chugs to sound powerful? Breakdowner got you.

Example:
A creative audio effect plugin built with JUCE that allows users to distort any signal, doesn't matter if its a guitar, a bass, even drums, Breakdowner will give you that heavy sound you need.

---

## Features
- A distortion Knob to graduate te amount of clipping you want on your signal
- A tone knob designed to clear the top end of the spectrum
- Volume and Blend controls to regulate the sound and level of the overall distortion

---

## Tech Stack
- C++
- JUCE Framework
- VST3 SDK

## Installation (Windows)
1. Download the latest release
2. Copy `.vst3` file to:
   C:\Program Files\Common Files\VST3\
3. Open your DAW and rescan plugins if necessary

2. Export project
